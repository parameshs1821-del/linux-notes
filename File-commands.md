1. FILE COMMANDS
    ========================================

Command Name : pwd
Purpose      : Display the current working directory.
Syntax       : pwd
Example      : pwd
Sample Output:
/home/paramesh/Documents
Explanation  : Shows the location of the current directory.

⸻

Command Name : ls
Purpose      : List files and directories.
Syntax       : ls [options]
Example      : ls
ls -l
ls -a
Sample Output:
Documents  Downloads  Pictures
Explanation  : Displays the contents of a directory.

⸻

Command Name : cd
Purpose      : Change the current directory.
Syntax       : cd directory_name
Example      : cd Documents
cd ..
cd ~
Sample Output:
(No output if successful)
Explanation  : Moves from one directory to another.

⸻

Command Name : mkdir
Purpose      : Create a new directory.
Syntax       : mkdir directory_name
Example      : mkdir LinuxPractice
Sample Output:
(No output)
Explanation  : Creates a new folder.

⸻

Command Name : touch
Purpose      : Create an empty file.
Syntax       : touch filename
Example      : touch notes.txt
Sample Output:
(No output)
Explanation  : Creates an empty file if it does not exist.

⸻

Command Name : cp
Purpose      : Copy files or directories.
Syntax       : cp source destination
Example      : cp notes.txt backup.txt
Sample Output:
(No output)
Explanation  : Creates a copy of a file or directory.

⸻

Command Name : mv
Purpose      : Move or rename files/directories.
Syntax       : mv source destination
Example      : mv notes.txt Documents/
mv old.txt new.txt
Sample Output:
(No output)
Explanation  : Moves or renames files and directories.

⸻

Command Name : rm
Purpose      : Remove files.
Syntax       : rm filename
Example      : rm notes.txt
Sample Output:
(No output)
Explanation  : Permanently deletes a file.

⸻

Command Name : rmdir
Purpose      : Remove an empty directory.
Syntax       : rmdir directory_name
Example      : rmdir TestFolder
Sample Output:
(No output)
Explanation  : Deletes an empty directory.
